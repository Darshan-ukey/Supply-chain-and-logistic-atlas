# Supply Chain Atlas V2.1 RC1

This release corrects the V2.0.3 handoff by rebasing the frozen Atlas V2.1
Execution Fabric onto every later frozen/product asset created on 1 September
2026. It includes Universal Ask across Universe, daughters, Canvas and Admin;
Universe V7.3; Road LTL V1.3; Ocean FCL/LCL V0.5; Foundation V1.2; Atlas
Warehouse V1; and Canvas V2.0.

The release remains an RC until the GitHub branch is deployed to Lab and the
browser/mobile suite plus Supabase migration are certified in the deployed
environment.
