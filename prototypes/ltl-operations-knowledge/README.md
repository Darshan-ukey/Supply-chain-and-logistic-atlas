# Atlas Road LTL — Operations Knowledge Prototype

Open `index.html` directly in a browser. It is a self-contained standalone prototype and makes no backend/API calls.

The prototype is positioned at **Road LTL → Work Definitions → Operations Knowledge** and contains four researched proof cases:

- LTL-04 Pickup request & readiness
- LTL-06 Origin receipt & handling-unit state
- LTL-18 U.S. cargo claim adjudication
- LTL-19 U.S. hazardous-material hold/release

`operations-knowledge-v0.1.json` is the structured candidate data model for future integration.

`RESEARCH_FINDINGS.md` records the audit and scope boundaries.
