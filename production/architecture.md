# Stage 17 — Production Platform Boundary

## Purpose
Stage 17 separates the governed Atlas/canvas runtime from authenticated client work and persistence without changing canonical Atlas knowledge.

## Runtime boundary

```text
Browser / Canvas
  ├─ Canonical Atlas assets (read-only)
  ├─ Stage 16 deterministic rules / overlays / version pins
  └─ Stage 17 workspace bridge
          ↓ HTTPS, same-origin
Vercel API functions
  ├─ HttpOnly auth cookies
  ├─ explicit endpoint allow-list
  ├─ no service-role key in browser
  └─ forwards authenticated user JWT
          ↓
Supabase
  ├─ Auth
  ├─ Postgres + RLS
  ├─ private evidence bucket
  └─ append-only audit events generated by triggers
```

## Knowledge spaces
- **Global Atlas**: read-only, governed module/catalog assets. No client facts.
- **Client workspace**: mappings, evidence, validation, opportunities, future state and saved views.
- **Audit trail**: database-generated record of client-work mutations.

## Non-negotiable boundary
A client workspace can reference canonical Atlas IDs, but it cannot mutate canonical Atlas modules. The UI may continue to work in local Lab mode, but any real client data must use an authenticated workspace.

## Stage 17 storage model
- `atlas_workspaces`
- `atlas_workspace_members`
- `atlas_client_states`
- `atlas_saved_views`
- `atlas_evidence_files`
- `atlas_findings`
- `atlas_opportunities`
- `atlas_future_states`
- `atlas_knowledge_gaps`
- `atlas_audit_events`
- private Storage bucket: `atlas-client-evidence`

## Authentication
Access and refresh tokens are stored only in Secure, HttpOnly, SameSite=Lax cookies issued by Vercel functions. The browser does not receive Supabase API credentials or persist auth tokens in localStorage.

## Tenant isolation
Every client-work table has RLS enabled. Workspace-scoped policies call private membership helpers. Evidence object paths begin with the workspace UUID and storage policies enforce membership against that prefix.

## Evidence upload
The Stage-17 reference API proxies files up to 4 MB and writes SHA-256 + metadata. The bucket allows up to 20 MB. For production-scale documents, replace the proxy with a signed direct-upload path while retaining the same RLS/object naming contract.

## Local fallback
If the API is unavailable or the user is signed out, the Stage-16 canvas continues in explicit **Local Lab Mode**. Local mode is not suitable for client-confidential evidence.
