Two-direction discovery · full enterprise envelope

Find white space without declaring it too early

Top-down outcomes and bottom-up execution friction meet at the selected process boundary. A mode may emphasize its Execution Core, but it never removes the broader enterprise dependencies that can cause, constrain, monetize or receive consequences from execution.

Top-down: outcome and control

Enterprise outcome → lens → mode/service → process → node → decision/control → execution evidence.

Bottom-up: event, handoff and exception

Execution event/problem → process → node → mode → upstream/downstream domains → enterprise outcome.

Root-cause versus failure-location rule

The location where a failure becomes visible is not necessarily the process where the root cause originated. Trace across nodes, roles, systems, objects and upstream/downstream domains before assigning ownership.

Freight reclassification · visible in rating/billingPossible root: product master, dimensions, weight or classification.
Missed pickup · visible in transportPossible root: capacity planning, provider allocation or dock readiness.
Damage claim · visible in claimsPossible root: packaging, node handling, terminal operation or securement.
Billing dispute · visible in financePossible root: contract, rate, execution evidence or master data.

Diagnostic questions for the neutral ecosystem

    Guardrail: A gap in visibility, automation or data quality is not proof of value. Validate frequency, materiality, root cause, owner, existing controls and economics before design.
