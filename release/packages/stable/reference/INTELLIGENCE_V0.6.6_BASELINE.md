# Atlas Intelligence v0.6.6 baseline retained by Pilot V1.0

The historical v0.6.6 release was a runtime presentation/simulation/explanation layer over unchanged Atlas V6.2.3 content, frozen Page 0 V6.2.2 and Road LTL V1.2.

Retained capabilities in the cumulative Pilot V1.0 experience:
- adaptive information density / Work-like quiet canvas;
- Active Context Ribbon;
- deterministic 13-step STANDARD Road LTL execution spine;
- Play/Pause/Previous/Next/Reset/Freeze/speed;
- process/task inspection;
- Physical, Information, Data/Document, Financial and Control/Evidence execution signals;
- governed handoff/lineage presentation;
- Risk/Control and Reference ↔ Client comparison boundaries;
- explicit exception state without automatic recovery-route selection;
- current-simulation state passed into Ask Atlas;
- allow-listed visual commands with governed ID validation;
- LLM explains grounded state but cannot invent process paths, applicability or payload fields.
