# Supply Chain Operations Intelligence Platform v1.1.8

## Scope

v1.1.8 is a governed-composition release built from the exact certified v1.1.7 final GitHub master. It does not replace or rewrite the canonical Atlas foundation.

### Additions

- Complete Page-0 **71-destination navigator** in the modern product surface.
- Four primary canvas entry routes: **Mode / Service, Enterprise Process / End-to-End Domain, Operating Model / Actor, Logistics Node**.
- Universal Search / Ask / Trace remains cross-cutting.
- Exhaustive Page-0 compatibility lattice: **711 pairwise rules + 20 cross-axis prerequisite / interaction rules**.
- Governed context composer with direct, conditional, prerequisite, unavailable, research and reference-only states.
- Separate **Road LTL Execution Role / Perspective** refinement sourced from the child module. It does not alter or expand the 19 Page-0 Operating Models.
- Deterministic **configuration → canonical graph resolver → canvas** pipeline.
- Reverse-entry resolution from enterprise domain, operating model or logistics node into compatible modes.
- 27 enterprise lenses and 9 executive cycles preserved as analytical views, not process taxonomy.
- Source-alignment audit against the preserved Page-0 compatibility profiles and mode relevance model.
- Graph validation proving active edges remain exact canonical Road LTL edges, playback contains only relevant/conditional tasks, and semantic canvas state matches the resolved graph.
- Saved Views capture and restore the governed v1.1.8 composer + entry state.

### Inspector validation

- The A5 Inspector remains driven by the canonical Road LTL record.
- Browser certification compares rendered values directly against trigger, before/after state, event, decision, rule, control, clock, action, evidence, outcome, responsibility, inputs/outputs, systems/authority and source IDs.
- The v1.1.8 **Governed composed context** section is additive; it does not replace or rewrite the canonical A5 contract.
- Playback/Freeze and Trace retain their specialized Inspector views.

### Ask Atlas validation

- Stage 18 now includes `page0Composition` and `entryState` in the canvas state sent to Ask Atlas.
- Validated `set_context_option` commands route through the v1.1.8 governed composer when available instead of writing directly to the legacy context layer.
- Server-side Ask Atlas remains retrieval-first and citation-validated.
- Deterministic fallback works when Gemini is not configured.
- Coverage guardrails explicitly refuse unpublished Ocean/other-mode A4/A5 synthesis.

### Protected v1.1.7 behavior

- Exact Reference Atlas Page 0 V6.2.3 navigation.
- Exact Road LTL V1.2 reference navigation.
- Spatial 15-territory Universe, ambient mesh, minimap and non-boxed renderer.
- Semantic zoom: **Universe → focused A3 → scoped A4 → A5 contract**.
- Playback, Freeze Time, five signals, Trace, Actor/System/Control/Source lenses, Compare and Transform.
- Client AS-IS, discovery, validation, opportunity and TO-BE flows.
- Stage 17, 19, 20 and 21 remain byte-identical to v1.1.7; Stage 18 changes only for the governed-context integration described above.
- Canonical Page 0, Road LTL, Enterprise Core, Supply Chain Domain Pack, Data Contract v1.1, relationship/rule/overlay registries and migrations remain protected.
- 8 Vercel functions / 28 public API paths.

### Coverage guardrail

Road LTL V1.2 remains the only A5-verified execution module. Other modes and enterprise destinations may be navigated and composed at their published reference depth, but v1.1.8 does not invent A4/A5 execution for them.

### Release status

**Local release certification only.** Live Gemini provider certification and deployed Vercel Lab E2E remain external deployment gates.
