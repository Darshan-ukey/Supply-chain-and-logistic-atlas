== Independent review (two rounds, separate agent)
Round 1 checked GitHub's documentation, the runner-image sources and experiments. It confirmed the Actions semantics (path
filters, job permissions, GITHUB_TOKEN pushes not triggering runs, artifacts, PostgreSQL 16 on ubuntu-24.04, the auth-header
pattern). It found false-PASS paths (a name-agnostic historical skip; unchecked names, subfolders and symlinks; a pin without
a file; duplicate YAML keys; .gitattributes byte filters), a publisher ref-ambiguity defect and overstated test claims.
Round 2 confirmed those closed and found more variants (N1-N4: pinned or unpinned ATL-82 SQL under other names or folders,
a mixed-case pin with no file, a pin smuggled through the YAML path; N6: a decoy branch that blocked the first publish).
All are fixed and covered by scenarios S6, S9-S16, N1-N4 and publisher cases P1, P5b and P9.

== Known limits and open risks (not fixed by code; for the handoff)
- Landing order: the ATL-83 gate, pack and output must be present, and the runner and publisher must land before or with
  the workflow file; otherwise the first run fails (or the publish job fails with 'No such file').
- The credential that pushes .github/workflows/ needs workflow permission (PAT 'workflow' scope or App 'workflows' permission).
- A branch ruleset covering all branches (restricting creation or requiring PRs) would block the proof-branch push.
- workflow_dispatch works only once the workflow file is also on the default branch (main).
- CI runs PostgreSQL 16.15 (apt.postgresql.org); the golden results were recorded on 16.13. The canary turns any drift into
  a visible FAIL, never a silent PASS.
- A candidate that later fails QA and stays in the repo keeps failing CI until it is added to the runner's historical list
  (a governed edit).
- by-commit/<sha>.md shows whichever run published last for that commit; INDEX.tsv keeps every run.
- A proof names the CI code blobs of its source commit; readers must accept a PASS only when those equal the reviewed blobs
  listed above.

== Appendix A: run_tests.sh
#!/usr/bin/env bash
# ATL-94 local test: executes the gate job's own `run:` blocks, extracted from the workflow YAML, with `bash -e`
# (GitHub's default shell for run steps), as a non-root user. GITHUB_ENV is emulated between steps.
set -u
T=/var/tmp/atl94test; cd $T/repo || exit 1
WF=.github/workflows/atl94-candidate-sql-gate.yml
export RUNNER_TEMP=$T/rt; rm -rf "$RUNNER_TEMP"; mkdir -p "$RUNNER_TEMP"
export GITHUB_ENV=$RUNNER_TEMP/github_env; : > "$GITHUB_ENV"
unset PGHOST PGSERVICE PGHOSTADDR PGSERVICEFILE
step() { # extract the run block of the gate-job step with this exact name
  python3 - "$WF" "$1" <<'PY'
import sys, yaml
wf = yaml.safe_load(open(sys.argv[1]))
for s in wf['jobs']['gate']['steps']:
    if s.get('name') == sys.argv[2]:
        print(s['run']); break
else:
    sys.exit("step not found: " + sys.argv[2])
PY
}
job_env() { python3 -c "import yaml,sys; e=yaml.safe_load(open('$WF'))['jobs']['gate']['env']; print(' '.join(f'{k}={v}' for k,v in e.items()))"; }
for kv in $(job_env); do export "${kv?}"; done
echo "job env from workflow: $(job_env)"
step 'Start a disposable PostgreSQL 16 (Unix socket only)' > $RUNNER_TEMP/step_pg.sh
step 'Ensure PyYAML' > $RUNNER_TEMP/step_yaml.sh
step 'Run the ATL-83 gate against every ATL-82 candidate (with canary)' > $RUNNER_TEMP/step_run.sh
bash -e $RUNNER_TEMP/step_pg.sh; echo "start step exit $?"
bash -e $RUNNER_TEMP/step_yaml.sh; echo "PyYAML step exit $?"
while IFS= read -r kv; do export "${kv?}"; done < "$GITHUB_ENV"
echo "GITHUB_ENV exported: $(cat "$GITHUB_ENV" | sed "s#$T#<T>#")"
echo "cluster: $(psql -X -At -d postgres -c 'show server_version'); listen_addresses=[$(psql -X -At -d postgres -c 'show listen_addresses')]; collation $(psql -X -At -d postgres -c "select datcollate from pg_database where datname='template1'")"
G="git -c user.name=t -c user.email=t@t"
I=governance/implementation; V3=$I/ATL_82_CANDIDATE_PHYSICAL_MIGRATION_V0_3.sql; V02=$I/ATL_82_CANDIDATE_PHYSICAL_MIGRATION_V0_2.sql; M=governance/task-manifests/ATL-82.yaml
BASE=$(git rev-parse HEAD); export BASE
standin() { sed -e '214s/ as [$]$/ as $$/' -e '226s/^end [$];$/end $$;/' -e "221s/col = any (tg_argv)/col = any (coalesce(tg_argv, '{}'::text[]))/" $V02; }
pinpath() { # $1 path $2 blob [$3 extra yaml line]
  python3 - "$M" "$1" "$2" "${3:-}" <<'PY'
import sys; p,path,b,extra=sys.argv[1:5]; s=open(p).read()
e=f"working_outputs:\n  - path: {path}\n    blob_sha: {b}\n" + (f"    {extra}\n" if extra else "") + "    state: IMPLEMENTED_UNVERIFIED\n"
assert s.count("working_outputs:\n")==1; open(p,'w').write(s.replace("working_outputs:\n",e))
