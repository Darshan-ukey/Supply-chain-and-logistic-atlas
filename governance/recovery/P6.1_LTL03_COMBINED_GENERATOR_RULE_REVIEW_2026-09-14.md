## 3. Specific reconciled answers

**Primary spine:** Yes. The 20-item `workDecompositionSeed` is the primary source-grounded spine. Expansion requires distinct child-level execution contracts independently supported by source.

**Object/workflow detail versus child creation:** Detail remains inside the parent unless it represents a separately evaluable operation or gate with independently sufficient source support.

**Sequence/order:** It may establish pre-state/order only, never the substantive rule, authority, validation logic, failure semantics, or exception routing.

**Blocker propagation:** Parent-level unresolved semantics/bindings block the composite unless the source independently supports a child decomposition that can be evaluated separately.

**Validation/conflict/HITL:** Generic labels are insufficient. Actual criteria, thresholds, precedence, or routing semantics must be source-supported or fail closed.

**Canonical authority/role:** Apply corrected CR10 at executable-leaf level only where authority is material. Policy objects do not need actors merely because they are policies. Runtime executor assignment is outside this requirement.

**Failure/alternate transitions:** Apply CR11. Task-level exception policy may be inherited where genuinely applicable without requiring optional fields mechanically on every leaf.

**Grouped-family semantics:** Respect explicit grouped-family language such as DangerousGoods; do not decompose independent universal fields where source defines one associated conditional object family.

**Permanent compiler versus manual review:** CR1–CR9 are suitable as generic compiler rules. CR10 and CR11 are generic requirements but require a review checkpoint for applicability: whether authority is material, whether a policy actually assigns responsibility, and whether a task-level exception policy genuinely covers the leaf’s failure mode.

## 4. Expected impact on regeneration

CR1/CR2 should collapse the current over-expanded 64-unit structure toward the source-supported 20-step spine, expanding only where independent child execution contracts exist.
