# v0.6.4 Semantic Guardrails

1. Canonical Atlas/UI vocabulary is resolved before generic process retrieval.
2. Active page/state may disambiguate a visible UI term, but cannot create Atlas facts.
3. Object trace anchors must resolve to an existing governed Road LTL process and existing graph relationships only.
4. Ambiguous terms may return bounded candidates; the resolver must not fabricate an entity or relationship.
5. “Other” is explained according to its actual Atlas context; the current Page-0 literal is `Other national / corridor jurisdiction`, not a generic source category.
6. LLM remains synthesis-only over the evidence packet. Canonical resolver, graph and source data remain authoritative.
7. No semantic improvement adds Atlas write capability. Corrections remain manual/admin-governed.
