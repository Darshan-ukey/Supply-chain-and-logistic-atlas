# Scenario / Client Twin governance

Atlas Component = source-backed process/node/rule/relationship.
Overlay = composable variation such as jurisdiction, condition, operating model or exception.
Configuration = user-created/saved combination.
Reference Scenario = deliberately curated, human-approved reusable example.

Client workspaces are overlays on the Atlas, not Atlas mutations. Unknown remains unknown. Reference-only is not client truth. Inferences are not automatically promoted. Deviations are not automatically defects. Human approval governs client facts, TO-BE designs and any future Atlas correction.
