# v0.6.3 usability/runtime patch

Frozen Atlas content is unchanged.

## Fixes
- Intelligence/chat panel is collapsible. Minimized state gives the Atlas the full viewport; a small `Ask Atlas` control restores the panel.
- Header shows live LLM state from `/api/capabilities`: provider/model when connected, otherwise `LLM OFF · deterministic fallback`.
- `track POD` and similar acronym/object requests now resolve strongly to the governed process model instead of falling below retrieval threshold.
- Lineage requests issue a `TRACE_PROCESS` UI action across the immediate governed upstream/downstream neighborhood.
- Atlas-native terms such as `movement pattern`, `operating role`, `carriage regime`, `jurisdiction`, `node`, `lens`, `trace` and `simulation` are accepted by the Trust Gate.
- Client operating-model requests load the governed LTL reference backbone as `REFERENCE_ONLY`; missing client facts remain unknown and are not invented.

## Tested examples
- `track POD` -> LTL-13 + trace action: PASS
- `what's movement pattern???` -> Trust Gate ACCEPT + full-Atlas retrieval: PASS
- `can you build me FedEx LTL operating model` -> REFERENCE_ONLY client-mapping response + reference-flow action: PASS
- all six retained regression suites: PASS

## LLM activation
The gateway already supports Gemini, OpenAI and Anthropic. It remains in deterministic fallback until server-side Vercel environment variables are configured. No API key belongs in browser HTML.
