# v0.6.4 LLM setup on Vercel

Open the Vercel project -> Environment Variables and add server-side variables.

For Gemini:
- `LLM_PROVIDER=gemini`
- `LLM_MODEL=gemini-2.5-flash`
- `GEMINI_API_KEY=<your Gemini API key>`

Apply to Production and, while testing, Preview. Redeploy after saving the variables.

The key must never be added to `public/atlas.html`, client JavaScript, the ZIP, GitHub source or browser local storage.

After redeploy, `/api/capabilities` should report `llm.enabled=true`, and the UI badge should change from `LLM OFF · deterministic fallback` to the configured provider/model.
