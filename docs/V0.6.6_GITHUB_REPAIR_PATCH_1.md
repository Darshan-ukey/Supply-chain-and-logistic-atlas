# Atlas Intelligence v0.6.6 — GitHub/Vercel Repair Patch 1

## Trigger
Vercel build for Git commit `f9fce15` failed because GitHub did not contain two runtime files that were present in the packaged v0.6.6 ZIP:

- `lib/simulation/engine.js`
- `lib/runtime/ui-actions.js`

The imports in `app/api/simulation/route.js`, `lib/agents/orchestrator.js`, and `lib/runtime/capabilities.js` were therefore unresolved in the cloned repository.

## Repair
- Restore the two missing runtime files.
- Set `engines.node` to `24.x` because Vercel project settings are already Node 24 and Node 20 is deprecated.
- Add `scripts/verify-deploy.mjs`.
- Add `prebuild` verification so a future omitted file fails with an explicit deployment-file message before Next.js compilation.

## Non-changes
No frozen Atlas, Road LTL model, V6.2.3 guide, Constitution, process relationship, simulation semantic, client-twin rule, or LLM behavior is changed by this repair patch.
