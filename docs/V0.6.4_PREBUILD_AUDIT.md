# v0.6.4 Pre-build Audit

Baseline: v0.6.3 frozen Atlas/integrity and six regression suites preserved.

## Release blockers found
1. Trace by explicit LTL process works, but semantic object tracing is inconsistent for ambiguous nouns such as invoice, claim, rate and billing.
2. Atlas UI/glossary concepts are not resolved before process search; labels such as OTHER, movement pattern, source-native backbone, governed evidence universe and authority domain can be misrouted.
3. Chat request context does not contain enough current Page-0/Road-LTL UI state to resolve deictic questions such as “what does this mean?”.
4. Trust Gate vocabulary is regex-maintained rather than aligned to the canonical Atlas vocabulary.
5. LLM gateway exists and is safe, but runtime capabilities do not clearly expose the exact environment-variable names required to activate it.

All five are blockers for the “explain anything visible on the Atlas” requirement.
