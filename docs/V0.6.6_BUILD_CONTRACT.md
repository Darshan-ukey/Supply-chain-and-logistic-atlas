# Atlas Intelligence v0.6.6 — Build Contract

## Objective
Convert the Atlas from a detailed read-only reference into an interactive reference execution twin while reducing visual overload and preserving every governance boundary.

## Stage plan
0. Freeze baseline and run the v0.6.5 regression/integrity suite.
1. Adaptive Information Density and Active Context Ribbon.
2. Deterministic Simulation Engine and Journey UI.
3. Handoff, Data, Risk, Control and provenance intelligence.
4. Client Twin comparison and chatbot/simulator integration.
5. Full regression, semantic, security, UI-contract and packaging audit.
6. **Independent post-build re-audit** of the finished package using separate assertions.

## Required experience
A user should be able to answer, without reading every detailed card:
1. Where am I in the journey?
2. Who and which system are involved?
3. What physical, information and financial things are moving?
4. What data/evidence crosses the handoff?
5. What could prevent the next step and what control addresses it?
6. Where did this statement come from?

## In-scope epics
- Work/Learn modes.
- Collapsible governance/reference sections.
- Persistent Active Context Ribbon and on-demand context editing.
- Contextual Constitution help.
- Full-workspace Simulation Studio.
- Deterministic standard journey and explicit non-standard relationship handling.
- Process/Actor/System/Node swimlanes.
- Physical/Information/Financial/Controls/Evidence threads.
- Step and Handoff Inspectors.
- Data Exchange Registry and lineage.
- Risk & Control view with provenance.
- Explicit exception/recovery simulation.
- Reference / Client AS-IS / Client TO-BE comparison.
- Simulation-aware chat and strict UI action validation.
- Separate Query vs Evidence Intake trust gates.
- Product-level simulation telemetry.

## Explicitly not in scope
- Live GPS/IoT or carrier telemetry.
- Predictive ETA or stochastic transit models.
- Route optimization.
- Quantified risk probability/financial loss without actual data.
- Automatic client fact promotion.
- Automatic Atlas correction.
- New FTL/Ocean/Air execution children.

## Release boundary
Page 0 V6.2.2, integrated Road LTL V1.2, deployed V6.2.3 guide, extracted Road LTL model and Constitution V6.2.3 are immutable inputs for this release.
