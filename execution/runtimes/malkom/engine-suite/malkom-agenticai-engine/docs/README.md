# docs

Two standalone HTML documents. Open either directly in a browser.

- **`engine-spec.html`** — *Malkom Agent Engine*. The plan: how agents are built,
  answered challenge by challenge. The engine is the definition centre; the hosts
  comply.
- **`build-handover.html`** — *Building on the Agent Engine*. The build handover for
  the colleague taking the UI and the plumbing forward: what the engine exposes,
  consumes and emits, every pipe named, and abstract guidelines for Command and the
  runtime.

Both are self-contained (fonts load from Google Fonts) and theme-aware — they follow
the viewer's light/dark preference.
