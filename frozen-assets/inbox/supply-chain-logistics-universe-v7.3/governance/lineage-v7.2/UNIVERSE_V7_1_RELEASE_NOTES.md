# Universe V7.1 — Release Notes

## Purpose

Universe V7.1 is the first closed-loop correction release after the Ocean FCL/LCL draft. It promotes only the generic parent/source-governance findings already identified from that daughter-module research.

## Approved V7 → V7.1 changes

1. Add **UN/CEFACT International Forwarding and Transport BRS · Overall v2** as a governed parent source for generic forwarding/multimodal process scope.
2. Add **SMDG** as a governed terminal/carrier message-evidence family, with exact stable message-guide versions bounded by implementation/adoption context.
3. Add **FMC OTI/OFF/NVOCC** as an explicitly **U.S.-jurisdiction-only** role/regulatory source.
4. Keep **CTU Code 2014** as the active published baseline while recording the **2025 revision / 2026 finalization cycle** as a non-promoted source watch.

## What did not change

- 71 navigator destinations.
- 27 enterprise lenses / 9 cycles.
- A3/A4/A5 daughter content.
- Road LTL V1.2.
- Enterprise Core / Domain Pack / Atlas Data Contract.
- Context rules, compatibility combinations, roles, movement patterns, logistics nodes, systems, objects, documents, relationship vocabulary or exchanges.
- Location Master canonical ID/name/aliases.

## Correction loop

Any new parent-level issue discovered during V7.1 or the final Ocean build is recorded in the **Universe V7.2 candidate queue**. V7.1 is not reopened silently.
