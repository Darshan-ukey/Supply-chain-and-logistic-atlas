# Ocean FCL/LCL V0.5 Release Notes

V0.5 is the first Ocean daughter release authored directly to Atlas Daughter Module Production Standard V1.

## What changed
- Replaced static A3/A5 card-dump pages with the common daughter application experience derived from Road LTL V1.3.
- Added governed context composer, one-graph/multi-projection execution view, reference configurations, enterprise lenses, deep Sources view and six-tab A5 Inspector.
- Added structured upstream/downstream lineage, semantic zoom labels, Canvas territories, system exchange references, temporal constraints, document relevance, responsibility models and field-level provenance claims.
- Expanded task-level enterprise-lens crosswalks while retaining the inherited Universe lens registry.

## What did not change
- Existing A3 identities, 30 process IDs per module, core execution semantics, 56 graph edges, 30 transitions, 240 ontology edges, applicability, event/state/decision/rule/control/action/evidence/outcome IDs, existing Producer/Authority/Consumer system roles and source claim boundaries.
- Universe V7.3 is not changed.
- Canvas architecture is not changed.
